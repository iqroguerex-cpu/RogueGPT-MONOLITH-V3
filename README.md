**RogueGPT-Monolith-V3** is a grand, high-performance neural interface engineered for precision AI interaction. 

> **Engineered & Designed by Chinmay V Chatradamath**

## 💎 Features
* **🏛️ Monolithic UI:** Custom CSS-injected borderless interface.
* **🧠 Multi-Engine Core:** Toggle between Arcee Trinity, DeepSeek R1, Qwen3, and more.
* **⚡ Pulse-Stream:** Real-time token streaming with a monolithic block cursor.
* **🧹 Auto-Purge:** Intelligent session clearing on engine switch.

## 🚀 Deployment Strategy
1. Push code to GitHub.
2. Deploy via Streamlit Community Cloud.
3. Add `OPENROUTER_API_KEY` in **Advanced Settings > Secrets**.
